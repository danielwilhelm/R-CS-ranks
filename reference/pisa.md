# Cross-country comparison of students' achievement

**\[deprecated\]**

New code should use `data(pisa2018)` instead.

Dataset containing average scores on math, reading, and science together
with standard errors for all OECD countries. These are from the 2018
Program for International Student Assessment (PISA) study by the
Organization for Economic Cooperation and Development (OECD). The
average scores are over all 15-year-old students in the study.

## Usage

``` r
pisa
```

## Format

A data frame with 37 rows and 7 variables:

- jurisdiction:

  country, from which data was collected

- math_score:

  average score in math

- math_se:

  standard error for the average score in math

- reading_score:

  average score in reading

- reading_se:

  standard error for the average score in reading

- science_score:

  average score in science

- science_se:

  standard error for the average score in science
